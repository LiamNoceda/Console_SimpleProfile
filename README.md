# Simple Profile - Приветствие на C++

Простая консольная программа на C++, демонстрирующая вывод персональных данных (имени, возраста и страны) в консоль.

## Что делает программа
Инициализирует переменные с личными данными пользователя и выводит отформатированную приветственную строку в консоль.

## Исходный код проекта
```cpp
#include <iostream>
#include <string> // Обязательно для работы с типом std::string

int main() {
    int age{23};
    std::string name{"John"};
    
    std::cout << "Hello, World. I am " << age << " years old.\n"
              << "My name: " << name << " and i'm from USA\n";
              
    return 0;
}
```

## Как скомпилировать и запустить
Для сборки кода подойдет любой современный компилятор C++ (стандарт C++11 или новее).

```bash
# Компиляция программы
g++ main.cpp -o profile_app

# Запуск программы
./profile_app
```

## Пример вывода в консоль
```text
Hello, World. I am 23 years old.
My name: John and i'm from USA
```
